سياسة استخدام الذكاء الاصطناعي
نادي قادة الغد

الإصدار: 1.0
تاريخ السريان: 29 يوليو 2026
آخر تحديث: 29 يوليو 2026

1. الغرض

يعتمد النادي الذكاء الاصطناعي لدعم التعليم والقيادة والابتكار والإنتاجية والإبداع، مع مسؤولية وشفافية ونزاهة وإشراف بشري. الأداة تساعد الإنسان ولا تستبدل حكمه أو تعلمه أو مسؤوليته.

2. النطاق

تسري السياسة على الأعضاء والمكتب واللجان والمتطوعين والموجهين والمدربين والمتحدثين والمستخدمين والمطورين والمسؤولين، وفي المنصة والورش والمسابقات والأدوات الداخلية والمساعدات والأتمتة.

3. التعاريف

الذكاء الاصطناعي برنامج يولد محتوى أو يحلل أو يوصي أو يؤتمت؛ والمحتوى المولد يشمل النص والصورة والصوت والفيديو والبرمجيات؛ والإشراف البشري هو المراجعة أو الموافقة البشرية المناسبة.

4. المبادئ

يجب احترام المسؤولية والشفافية والعدالة والخصوصية والأمن والمساءلة والتصميم المتمحور حول الإنسان والإدماج والقيمة التعليمية والقانون.

5. الاستخدام المقبول

يجوز استعمال الذكاء الاصطناعي للتعلم والعصف الذهني والبرمجة وتحسين الكتابة والترجمة وتحليل البيانات والبحث والعروض والتخطيط والمسار المهني والإتاحة وأتمتة المهام المتكررة، مع التفكير النقدي والجهد الشخصي.

6. الاستخدام المحظور

يمنع الغش والانتحال وتزوير الشهادات أو الوثائق أو الحضور وانتحال الأشخاص ونشر تضليل متعمد وإنشاء برمجيات خبيثة أو محتوى غير قانوني أو مسيء والتحرش والتلاعب بالانتخابات وتجاوز التحقق أو مكافحة الاحتيال وإنشاء تزييف عميق بقصد الخداع أو الضرر.

7. النزاهة الأكاديمية

يجب استعمال الأداة كمساعد، والتحقق من المعلومات، والتصريح باستعمالها عندما تفرض قواعد المؤسسة أو المسابقة ذلك. يمنع إخفاء الاستعمال للحصول على أفضلية غير عادلة أو تقديم عمل مولد كعمل شخصي حين يمنع ذلك.

8. الإشراف البشري

لا يعتمد قرار مهم حصراً على مخرج آلي. تجب المراجعة البشرية للاتصالات الرسمية والشراكات والمالية والتأديب والوثائق القانونية والسلامة والإعلانات العامة.

9. الشفافية

يصرح بالمساعدة الجوهرية للذكاء الاصطناعي في المسابقات والمنشورات والمشاريع عندما يكون التصريح متوقعاً، وتوضح المنصة متى يتفاعل المستخدم مع نظام آلي.

10. المحتوى المولد

يتحمل المستخدم مسؤولية الدقة والمصادر والملاءمة والحقوق. يجب مراجعة الأخطاء وإزالة المحتوى الضار قبل النشر.

11. حماية البيانات

لا تدخل كلمات المرور أو المعرفات الخاصة أو البيانات المالية أو الطبية أو بيانات الغير أو الوثائق السرية في خدمة ذكاء اصطناعي إلا بتفويض وحماية وأساس قانوني مناسب.

12. المعلومات السرية

يمنع إدخال محاضر داخلية ومفاوضات وشؤون مالية وإجراءات أمن وقواعد أعضاء وبيانات إدارية وخطط غير منشورة إلى خدمة خارجية دون إذن صريح وضمانات.

13. ميزات المنصة

قد تشمل المساعدة في الكتابة والترجمة والبحث والأسئلة المتكررة والتوصيات والإرشاد. قد تتغير الوظائف وحدودها مع الوقت.

14. القرارات المؤتمتة

قد يدعم الذكاء الاصطناعي التوصيات والتصنيف وكشف الرسائل المزعجة أو الاحتيال، لكن القرارات المؤثرة في الأعضاء يؤكدها شخص مخول حيثما كان مناسباً.

15. الانحياز والعدالة

قد تكون المخرجات منحازة أو غير دقيقة. يجب فحص النتائج غير المتوقعة ومنع الاستعمال التمييزي والإبلاغ عن الانحياز الضار.

16. الأمن

يمنع استعمال الذكاء الاصطناعي للهجوم أو التصيد أو سرقة البيانات أو تجاوز المصادقة أو استغلال الثغرات أو تعطيل الحماية. قد يؤدي ذلك إلى توقيف فوري وإحالة للجهات المختصة.

17. الملكية الفكرية

يجب احترام حقوق المؤلف والعلامات والتراخيص وعدم إعادة إنتاج أعمال محمية بغير حق أو إزالة إشعار الحقوق أو ادعاء ملكية محتوى الغير.

18. أنشطة النادي

يجوز استعمال الذكاء الاصطناعي في الورش والبرمجة والتدريب والمسابقات والتنظيم والإتاحة والتحليل، مع إشراف بشري مناسب خصوصاً عند التقييم.

19. الإبلاغ

يمكن الإبلاغ بحسن نية عبر القنوات الرسمية مع وصف الحادث وتاريخه وأدلته. البلاغ الكاذب المتعمد مخالفة.

20. الإنفاذ

بحسب الخطورة، قد يطبق توجيه أو إنذار أو تدريب أو حذف محتوى أو تقييد ميزة أو توقيف نشاط أو عضوية أو إحالة للجهة المختصة، بصورة عادلة ومتناسبة.

21. التحديثات

تراجع السياسة عند تغير التقنية أو القانون أو التشغيل، وتنشر النسخة الحالية مع تاريخها.
