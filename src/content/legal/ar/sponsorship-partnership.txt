سياسة الرعاية والشراكات
نادي قادة الغد

الإصدار: 1.0
تاريخ السريان: 29 يوليو 2026
آخر تحديث: 29 يوليو 2026

1. الغرض

تضع هذه السياسة إطاراً شفافاً وأخلاقياً ومهنياً للتعاون مع المؤسسات التعليمية والشركات والهيئات العامة والمنظمات والمجتمع، بما يحمي استقلال النادي والثقة العامة.

2. النطاق

تسري على كل رعاية أو شراكة مع جامعة أو مدرسة أو شركة أو ناشئة أو إدارة أو مؤسسة عامة أو جمعية أو منظمة دولية أو مختبر أو مزود تقنية أو إعلام أو مهني.

3. التعاريف

الراعي يقدم دعماً مالياً أو مادياً أو تقنياً أو ترويجياً، والشريك يتعاون لتحقيق هدف مشترك، والتعاون نشاط أو مشروع أو حملة مشتركة، والمكتب التنفيذي جهة الموافقة.

4. المبادئ

يجب احترام النزاهة والشفافية والمهنية والاستقلال وتكافؤ الفرص والقيمة التعليمية والمنفعة المجتمعية والاحترام والقانون والاستدامة. لا تقايض رسالة النادي بالرعاية.

5. الجهات المؤهلة

يرحب النادي بالجهات المتوافقة مع أهداف التعليم والتكنولوجيا والأعمال والمجتمع والتطوع والخدمة العامة، بعد فحص السمعة والمشروعية والملاءمة.

6. فئات الرعاية

قد تشمل البلاتينية والذهبية والفضية والبرونزية والمجتمعية والتقنية والإعلامية، وتحدد المنافع والتزامات كل مستوى كتابة.

7. فئات الشراكة

قد تكون أكاديمية أو بحثية أو ابتكاراً أو ريادة أو تطوعاً أو مجتمعاً أو حكومية أو دولية.

8. طلب الرعاية

يقدم عبر القناة الرسمية مع ملف الجهة والتواصل والدعم المقترح والمستوى والميزانية والمدة والأهداف والمنافع المتوقعة.

9. الموافقة

كل تعاون يحتاج موافقة المكتب التنفيذي بعد تقييم توافق الرسالة والسمعة والقانون والقيمة التعليمية والشفافية والأثر وتعارض المصالح. يجوز رفض المقترح غير الملائم.

10. حقوق الراعي

قد تمنح كتابةً منافع متناسبة مثل الشعار والذكر في الموقع والفعالية ومساحة عرض وفرصة حديث ملائمة وتواصل وشهادة تقدير.

11. مسؤوليات الراعي

يجب احترام استقلال النادي وتقديم الدعم المتفق عليه واحترام القانون والطلبة والمتطوعين وتجنب الإعلان المضلل واستعمال العلامة بإذن والوفاء بالعقد. لا يتدخل الراعي في الحوكمة.

12. حقوق النادي

للنادي قبول أو رفض الجهة ومراجعة سلوكها وإزالة الاعتراف المبرر وحماية سمعته والتحكم في التنظيم والمحتوى والحفاظ على الاستقلال التحريري.

13. مسؤوليات النادي

يلتزم بالتواصل الصادق والاستعمال المسؤول للأموال واحترام الاتفاق والاعتراف العادل وحفظ السجلات والسرية وإنجاح التعاون.

14. العلامات والشعارات

تبقى هوية كل طرف ملكاً له. لا تستعمل أو تعدل إلا بإذن كتابي وللغرض والمدة المعتمدين.

15. الرعاية المالية

قد تمول المؤتمرات والورش والمسابقات والقيادة والمجتمع والاستضافة والمواد والمعدات والمنح والعمليات، مع سجلات مناسبة.

16. الدعم العيني

قد يشمل تراخيص وسحابة وذكاء اصطناعي ومعدات وطباعة ومكاناً وطعاماً ونقلاً واتصالاً وتسويقاً، ويمكن توثيق قيمته التقديرية.

17. الشراكات الأكاديمية

قد تشمل محاضرات وورشاً وبحثاً وإرشاداً وتدريباً مهنياً ومسابقات وابتكاراً، مع احترام الاستقلال الأكاديمي.

18. الشراكات الإعلامية

قد تشمل التصوير والبث والتغطية والحملات، وتظل القرارات التحريرية للجهة المختصة ما لم يتفق خلاف ذلك.

19. الشراكات التقنية

قد تشمل البرمجيات والسحابة وواجهات API والتكوين والإرشاد. لا يملك الشريك مشاريع النادي أو بيانات الأعضاء إلا باتفاق صريح وأساس قانوني مناسب.

20. شراكات الفعاليات

يجب تحديد الأدوار والميزانية والتسويق والتسجيل والسلامة والملكية والتقارير، ويوصى باتفاق مكتوب للتعاون الجوهري.

21. المعايير الأخلاقية

لا يتعاون النادي مع جهة تروج لنشاط غير قانوني أو عنف أو كراهية أو فساد أو استغلال الطلبة أو تمييز غير قانوني أو ضرر برسالته التعليمية.

22. تعارض المصالح

يجب على المسؤول أو المتطوع التصريح بأي تعارض فعلي أو محتمل والامتناع عن القرار عندما تتأثر حياديته.

23. الحصرية

التعاون غير حصري ما لم ينص اتفاق مكتوب خلاف ذلك، ويجوز التعاون مع جهات متعددة دون خرق التزامات قائمة.

24. السرية

يجب حماية المعلومات غير العامة، ولا تكشف إلا بإذن أو عند وجوب القانون أو الاتفاق.

25. حماية البيانات

لا يتلقى الشريك بيانات عضو أو متطوع أو مشارك إلا بموافقة مناسبة أو لضرورة خدمة مشتركة أو أساس قانوني، وبما يوافق سياسة الخصوصية.

26. الإعلانات العامة

تنسق الإعلانات بين الطرفين، ويمنع التضليل أو الإيحاء بتأييد أو منفعة تتجاوز الاتفاق.

27. الإنهاء

يجوز التوقيف أو الإنهاء عند خرق جوهري أو تعارض مع الرسالة أو سلوك غير قانوني أو أخلاقي أو خطر كبير، ويبلغ كتابياً حيثما أمكن.

28. المسؤولية

يتحمل كل طرف أفعاله وإغفالاته، ولا يسأل عن خسارة غير مباشرة إلا باتفاق أو حكم قانوني.

29. تحديث السياسة

تنشر النسخة الأحدث وتاريخها، ويخضع استمرار التعاون للاتفاق المكتوب والقانون.

30. التواصل

ترسل مقترحات وأسئلة الشراكة إلى contact@leadersoftomorrowestk.com أو نموذج «كن شريكاً» الرسمي.

31. القبول

بتوقيع اتفاق رعاية أو شراكة أو مذكرة أو تعاون، تقر الجهة بقراءة هذه السياسة وفهمها والالتزام بها.
